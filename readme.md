# Introduction
A Web Based 3D render virtual world allow user to navigate the avatar character to walkaround in a 3rd person view.

# Controls
The character control by keyboard AWSD, Space to Jump, Hold Shift to run.
Mouse move to look around.

# Character
Default: 3D Low Poly in T-Pose Model saved in /assets/characters/*.glb

# Web Portal
Run http_serve.bat to access via https://localhost:8080/
